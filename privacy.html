개인정보처리방침

Website Privacy Policy · 작성 기준일: 2026년 10월 24일

이 방침은 Future Soul Games 공식 홈페이지에 적용됩니다. 향후 출시되는 게임의 개인정보처리방침은 게임별 실제 데이터 처리 내용을 기준으로 별도로 제공합니다.

1. 운영자 및 적용 범위

Future Soul Games는 대한민국 개인사업자 꿈모아(영문 사업자명: DreamMoa)가 운영하는 게임 스튜디오 브랜드입니다. 이 홈페이지의 개인정보 관련 문의 창구는 futuresoulgames@gmail.com입니다.

2. 홈페이지에서 직접 수집하는 정보

이 홈페이지에는 회원가입, 로그인, 결제, 문의 입력 폼이 없습니다. 운영자가 별도의 방문자 데이터베이스를 구축하거나 방문 정보를 수집하는 자체 프로그램을 실행하지 않습니다. Google Analytics, 광고 SDK, 소셜 플러그인 및 외부 임베드 콘텐츠를 사용하지 않습니다.

홈페이지 코드에는 쿠키, 로컬 스토리지 또는 유사한 저장소를 통해 방문자를 추적하는 기능이 없습니다. 폰트와 시각 요소는 기기 기본 폰트 및 사이트 내부 리소스를 사용합니다.

3. 이메일 문의

이메일 링크를 선택하면 방문자가 사용하는 이메일 앱 또는 서비스가 열립니다. 링크를 누르는 것만으로 문의가 전송되지는 않습니다. 방문자가 이메일을 보내면 회신 주소, 발신자 표시 이름, 문의 본문 및 자발적으로 첨부한 자료가 운영자에게 전달됩니다.

  • 이용 목적: 문의 확인, 답변 및 관련 후속 소통
  • 보유 기간: 문의 처리가 끝나고 추가 보관 필요성이 없어지면 지체 없이 삭제합니다. 법령상 보관 의무가 있는 정보는 해당 법정 기간 동안 보관합니다.
  • 삭제 방법: 운영자가 관리하는 이메일 및 첨부파일을 삭제하며, 이메일 서비스의 보관·백업 처리에는 해당 제공자의 정책이 적용될 수 있습니다.

문의 수신에는 Gmail을 사용합니다. 이메일은 Google의 서비스 인프라에서 처리될 수 있으며, 처리 위치와 서비스 측 보관은 Google 개인정보처리방침을 참고해 주세요. 문의에 주민등록번호, 결제 정보 등 불필요한 민감정보를 포함하지 말아 주세요.

4. GitHub Pages 호스팅

이 홈페이지는 GitHub Pages 정적 호스팅을 사용하도록 구성되어 있습니다. GitHub Pages로 공개되는 경우 호스팅 제공자 GitHub는 서비스 제공, 보안 및 안정적인 운영 등을 위해 IP 주소, 요청 시각, 브라우저·기기 정보 등의 접속 정보를 처리할 수 있습니다. 이는 운영자가 홈페이지 코드에 별도의 분석 도구를 설치하여 수집하는 정보와 구분됩니다.

GitHub 측 정보 처리, 보관 기간 및 권리 행사 방법은 GitHub 개인정보처리방침에서 확인할 수 있습니다. GitHub 및 Google의 서비스 인프라에 따라 정보가 대한민국 외 지역에서 처리될 수 있습니다.

5. 제3자 제공 및 외부 링크

운영자는 문의 정보를 판매하거나 광고 목적으로 제공하지 않습니다. 법령에 따른 의무가 있거나 이용자가 별도로 동의한 경우를 제외하고, 문의 정보를 다른 목적으로 제3자에게 제공하지 않습니다. 이메일 및 호스팅 서비스 제공 과정에서의 정보 처리는 위에 설명한 각 서비스 정책에 따릅니다. 외부 사이트로 이동하면 해당 사이트의 개인정보처리방침이 적용됩니다.

6. 이용자의 권리와 문의 방법

운영자에게 제공한 문의 정보의 열람, 정정, 삭제 또는 처리 정지를 요청하려면 futuresoulgames@gmail.com으로 연락해 주세요. 요청자 확인에 필요한 최소한의 절차를 거쳐 관련 법령에 따라 처리합니다. GitHub 또는 Google이 독립적으로 관리하는 정보는 해당 제공자의 개인정보 문의 절차를 이용해야 할 수 있습니다.

7. 정보 보호 및 방침 변경

운영자는 문의 정보에 대한 접근을 업무상 필요한 범위로 제한하고, 보관할 필요가 없어진 정보를 삭제합니다. 데이터 수집 기능이나 외부 서비스를 추가하면 실제 처리 내용을 반영하여 이 방침과 작성 기준일을 갱신합니다.
